# Lightchain DAO proposals

Proposals to the Lightchain AI DAO, one folder each, with the discussion thread for each in this repository's Discussions. The on-chain vote happens on the Governor at chain 9200; this is where a proposal is read, argued over and revised before it gets there.

| Proposal | Status | Discussion |
| --- | --- | --- |
| [Compute grants to onboard independent AI power and decentralise the network](proposals/2026-10-compute-grants/) | Community discussion, opened 17 October 2026 | [Discussion 1](https://github.com/lightchain-protocol/lightchain-dao-proposals/discussions/1) |

## How a proposal moves

1. Posted here as a folder with a short summary and the full text, and a discussion thread opened.
2. Seven days of discussion. Changes are committed to the folder so the history of the text is public.
3. A summary of what changed is posted, and the proposal goes to the Governor. Voting runs about five days, then a 48-hour Timelock.
4. Executed proposals stay here with a link to the on-chain record.
